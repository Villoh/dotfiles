| `pi-fff` | Fast file and symbol discovery. |
| `pi-lens` | Code intelligence and diagnostics. |
| `pi-cliproxyapi-provider` | CliproxyAPI model provider. |

| `pi-notify` | Completion notifications. |
| `pi-background-tasks` | Background task management. |

## Disabled

| Package | Reason |
| --- | --- |
| `obra/superpowers` | Enable only when needed. |
| `@tintinweb/pi-tasks` | Untested and more than the simple todo workflow needs. |
| `pi-interactive-shell` | Its overlay interferes with terminal UX. |
| `pi-sandbox` | No Windows support; also requires `rg`. |
