# Hotkeys

Hyprland keybindings for NixOS + DMS: the DMS defaults plus the custom binds
declared in `nixos-config`.

- Source of DMS defaults: `~/.config/hypr/dms/binds.lua`, generated by
  `dms setup binds` (DMS v1.6.2, Hyprland 0.56.2, checked 2026-10-01).
  Do not edit it; `dms setup` only writes it when missing or empty.
- Source of custom binds: `modules/home/desktop/hyprland.nix` in
  `~/development/personal/projects/nixos-config`.
- `Super + Shift + /` opens DMS's own live cheat sheet.

Custom binds are additive: none of them overrides a DMS default.

## Custom (nixos-config)

| Hotkey | Function |
| ------ | -------- |
| `Super + B` | Default browser on a blank page (`xdg-open about:blank`) |
| `Super + C` | Editor from `$EDITOR` |
| `Super + Shift + V` | Discord client from `$DISCORD`, in Ghostty |
| `Super + Shift + Z` | WhatsApp (ZapFast) |
| `Super + Shift + S` | Region screenshot with annotation (`dms screenshot`) |
| `Super + Shift + M` | Toggle microphone mute |
| `Super + Shift + D` | Toggle speaker mute |
| `Ctrl + Shift + Space` | Push-to-talk dictation (Handy): toggles on press and on release |
| `Super + Alt + M` | Send `Alt + M` to the Concord window |
| `Super + Alt + D` | Send `Alt + D` to the Concord window |

### Focus and movement

Arrow keys and Vim keys (`H J K L`) are equivalent.

| Hotkey | Function |
| ------ | -------- |
| `Super + Arrows` / `Super + H J K L` | Focus window in direction |
| `Super + Shift + Arrows` / `Super + Shift + H J K L` | Move window in direction |
| `Super + Home` / `Super + End` | Focus first / last window |
| `Super + Ctrl + Left/Right` / `Super + Ctrl + H J K L` | Focus monitor in direction |
| `Super + Shift + Ctrl + Arrows` / `Super + Shift + Ctrl + H J K L` | Move window to monitor in direction |
