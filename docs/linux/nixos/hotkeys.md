# Hotkeys

Hyprland keybindings for NixOS + DMS: the DMS defaults plus the custom binds
declared in [`nixos-config`](https://github.com/Villoh/nixos-config).

- Source of DMS defaults: `~/.config/hypr/dms/binds.lua`, generated by
  `dms setup binds` (DMS v1.6.2, Hyprland 0.56.2, checked 2026-10-01).
  Do not edit it; `dms setup` only writes it when missing or empty.
- Source of custom binds: `modules/home/desktop/hyprland.nix` in
  `~/development/personal/projects/nixos-config`.
- `Super + Shift + /` opens DMS's own live cheat sheet.

Custom binds are additive: none of them overrides a DMS default.

## Touchpad gestures

Declared in `modules/home/desktop/hyprland/gestures.nix` (nixos-config) and rendered
to `hl.gesture()` Lua. Only the 3-finger horizontal workspace swipe comes from DMS
(`dms/binds.lua`).

The ASUP1415 touchpad reports up to 5 contacts, but libinput only emits swipes with
3+ fingers and pinches with 2+, and 5-finger gestures fire nothing (tested), so 3 and 4
fingers are what is bound. A 2-finger swipe is scrolling, and Hyprland has no hold or
tap gestures. A 2-finger pinch needs `Super`, otherwise it would take the zoom of the
browser and maps.

`Super + Ctrl + Shift + /` (docked AL68) or `Super + Ctrl + Alt + G` (laptop keyboard) open
DMS's keybind viewer on the gestures alone: the touchpad ones and, on the Zenbook, the
[touchscreen ones](#touchscreen-gestures-zenbook). The full viewer (`Super + Shift + /`, and
`Super + Ctrl + K` on the Zenbook) lists them together with the keybinds.

The viewer parses `hyprland.lua` without running it and reads `hl.bind` only, so
`gestures.nix` writes the gestures as `hl.bind` lines in two places: an `if false then`
block of the main config (the full viewer lists it, Hyprland never registers it) and a
sheet of its own that the two gesture keys open with `keybinds toggleWithPath`.

Same plane rule as the keys: no modifier is navigation, `Super` moves, resizes and
captures, `Alt` acts on the window, `Ctrl` is continuous controls and monitor/group
moves, `Shift` is media and shell toggles. The modifier is held on the keyboard while
swiping.

| Gesture | No modifier | `Super` | `Alt` | `Ctrl` | `Shift` |
| ------- | ----------- | ------- | ----- | ------ | ------- |
| 3 fingers left / right | Workspace (DMS, 1:1) | Move window 1:1 (horizontal) | Move window to previous / next workspace | Move window to left / right monitor | Previous / next track |
| 3 fingers up | DMS overview | Region screenshot to clipboard | Pop window out (float and pin) | Volume (live, vertical) | Play / pause |
| 3 fingers down | Scratchpad | Quake terminal | Close window | Volume (live, vertical) | Toggle microphone mute |
| 4 fingers left / right | Previous / next window | Resize window 1:1 (any direction) | Scroll the tape (scrolling layout) | Previous / next window in group | Focus previous / next monitor |
| 4 fingers up | Fullscreen | Resize window 1:1 | Maximize | Brightness (live, vertical) | Toggle bar |
| 4 fingers down | Toggle floating | Resize window 1:1 | Toggle dwindle / scrolling layout | Brightness (live, vertical) | Lock |
| 3-finger pinch / spread | Launcher / notification center | | | | |
| 4-finger pinch / spread | Control Center / quake terminal | | | | |
| 2-finger pinch or spread | | Zoom the screen at the cursor (live) | | | |

"Pinch" is fingers together and "spread" fingers apart. Hyprland names them `zoomout` and
`zoomin` (aliases of `pinchout` and `pinchin`); its wiki describes `pinchin` and `pinchout`
the other way round, but the source treats fingers together as `PINCH_OUT`.

Volume and brightness gestures are continuous: the swipe distance is accumulated and
fires one step (2 %) per `STEP` units, a constant at the top of `gestures.nix`. Raise it
if they feel twitchy.

## Touchscreen gestures (Zenbook)

Declared in `modules/home/desktop/hyprland/touchscreen.nix` (nixos-config). Hyprland only
turns touchpad swipes into gestures, so the Zenbook loads the
[hyprgrass](https://github.com/horriblename/hyprgrass) plugin
(`hosts/zenbook/touchscreen.nix`, built from `packages/hyprgrass`). The desktop has no
touchscreen and gets none of this. The panel (WDHT1F01) reports 10 contacts. Not tested
yet.

There is no modifier under the fingers, so the shape of the gesture is the plane: 3 fingers
navigate, 4 act on windows, 5 are destructive, and the screen edges open shell panels. 1
and 2 fingers stay with the apps (touch, scroll, zoom); hyprgrass always keeps 3 or more
from them. The viewer lists them under "Touch", in the full one (`Super + Shift + /`) and
in the gestures-only one (`Super + Ctrl + Shift + /`, `Super + Ctrl + Alt + G`).

| Gesture | 3 fingers | 4 fingers | 5 fingers |
| ------- | --------- | --------- | --------- |
| Swipe left / right | Workspace (follows the fingers) | Previous / next window | Move window to previous / next workspace |
| Swipe up | DMS overview | Fullscreen | Pop window out (float and pin) |
| Swipe down | Scratchpad | Toggle floating | Close window |
| Pinch (fingers together) | Launcher | Control Center | Lock |
| Spread (fingers apart) | Notification center | Quake terminal | |
| Tap | Play / pause | Region screenshot to clipboard | |
| Hold, then drag | Move window | Resize window | |

Edge swipes use one finger that starts within 30 px of the border (`edge_margin`):

| Edge | Swipe | Function |
| ---- | ----- | -------- |
| Bottom | Up | Launcher |
| Top | Down | Control Center |
| Left | Right | DMS overview |
| Right | Left | Notification center |
| Right | Along the edge (up / down) | Volume (live) |
| Left | Along the edge (up / down) | Brightness (live) |

Pinch and spread match the touchpad: fingers together (`zoomout`) opens the launcher and
the Control Center, fingers apart (`zoomin`) the notifications and the quake terminal.
hyprgrass reads the name with Hyprland's own parser, so they are the same aliases as in
`gestures.nix`.

The edge swipes and the live volume and brightness steps (the `STEP` constant in
`touchscreen.nix`) are the likeliest to need tuning: an edge swipe can collide with the bar
or an app's own edge.
